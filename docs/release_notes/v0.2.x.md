# v0.2.10

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.2.10

_Released 2026-06-03_

### Case studies & scenarios

- Fetch a complete case study in one call: the case with its source, sink, region, utilities, subsystems, scenarios and process settings, including their properties (`api.v2.get_cases_bundle`)
- Build ready-to-import case packs from cases and scenarios on the platform, matching the case-pack format used elsewhere in PrISMa (`api.v2.build_case_pack`, `build_case_spec`, `list_case_packs`)

### Materials & structures

- **Breaking:** listing materials now fetches every page for you, up to 10,000 records by default (`limit=0` for no cap); the `offset` argument has been removed (`api.v2.list_materials`)
- Material property bundles now prefer an exact name match and raise a clear error listing the candidates when a name is ambiguous, instead of silently mixing materials (`api.v2.get_material_property_bundle`)

### Adsorption & property data

- Water KPI results no longer include duplicate internal ID columns alongside the readable material and molecule names (`api.v2.get_water_kpis`)

# v0.2.9

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.2.9

_Released 2026-05-21_

### Case studies & scenarios

- Screening summaries can now be listed and looked up (`api.v2.get_screening_summaries`, `get_screening_summary`)

### Materials & structures

- **Breaking:** two v2 methods introduced in v0.2.8 were renamed: `get_materials` is now `list_materials` and `get_isotherms` is now `get_isotherm` (`api.v2.list_materials`, `api.v2.get_isotherm`)
- Fetch all isotherm, Zeo++ and water KPI data for a material in one call, or quickly check that a material exists (`api.v2.get_material_property_bundle`, `preflight_material_check`)

### Adsorption & property data

- Simulated and experimental Zeo++ results for carbon capture can now be read (`api.v2.get_carbon_zeopp`, `get_carbon_zeopp_experimental`)

### TEA / LCA data

- New read methods for equipment (with costs and designs), process conditions, process and contactor configurations, cost indices, constants and MEA baselines and KPIs (`api.v2.get_equipment`, `get_process_configurations`, `get_mea_kpis`)

### Reference catalog

- Transports, subsystems and properties can now be listed and looked up (`api.v2.get_transports`, `get_subsystems`, `get_properties`)

### Setup & configuration

- Choose whether list results come back as pandas DataFrames or plain JSON records (`api.set_return_format("json" | "dataframe")`)

# v0.2.8

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.2.8

_Released 2026-05-20_

### Case studies & scenarios

- First release of the v2 client, attached automatically to every client as `api.v2`, starting with case and scenario lookups (`api.v2.get_cases`, `get_scenarios`)

### Materials & structures

- Materials and their details can be read through the v2 client (`api.v2.get_materials`, `get_material`)

### Adsorption & property data

- Isotherms and water KPIs can be read through the v2 client (`api.v2.get_isotherms`, `get_water_kpis`)

### TEA / LCA data

- Output KPIs, region costs and ambient parameters can be read and uploaded (`api.v2.get_output_kpis`, `upsert_region_costs`, `upsert_ambient_parameters`)

### Reference catalog

- Look up molecules, elements, regions, CO₂ sources and sinks, transport scenarios, utilities and literature references (`api.v2.get_molecules`, `get_regions`, `get_references`)

### PSDI

- PSDI-format material listings and details, with CIF links ready to use as full URLs (`api.v2.get_materials_psdi`, `get_material_psdi`)

### Docs & examples

- New Python client reference and a full demo script covering both v1 and v2 (`API_REFERENCE.md`, `examples/prisma_api_demo.py`)

# v0.2.7

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.2.7

_Released 2026-04-15_

### v1 client

- Fetch the whole materials dataset in one call, split into simulated and experimental tables with nested CO₂ and Zeo++ fields unpacked into readable columns (`api.get_materials_data`)
- Materials results include full download links for CIF files and leave out internal ID columns (`api.get_materials_data`)

### Setup & configuration

- The client now uses the new production address, prisma-platform.org (`prisma_api.init()`)
- The client can run without a config file, reading its API key from an environment variable, and can be pointed at a dev server the same way (`init(use_config_file=False)`, `PRISMA_API_KEY`, `PRISMA_API_DEV`)
