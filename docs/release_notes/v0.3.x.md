# v0.3.8

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.3.8

_Released 2026-08-27_

### Materials & structures

- Look up materials by name (or a list of names) as well as by ID, with their isotherms, Zeo++ data, water KPIs and CIF details bundled in (`api.v2.get_material(name=...)`)
- Changed: looking up a material by ID now includes all related data by default; pass `bundle=None` to get just the material record as before (`api.v2.get_material`)
- New one-call shortcut fetches everything known about a material, optionally with its CIF file (`api.v2.get_material_bundle`)
- List materials that have CIF files and download them, either as files saved to a folder or as structured, cleaned-up data (`api.v2.list_cifs`, `get_cifs`), initially on a local dev server only

### Docs & examples

- New user guide and expanded API reference for material lookups and bundles (`user_guide.md`)

# v0.3.6

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.3.6

_Released 2026-07-09_

### Case studies & scenarios

- List case studies, optionally filtered by name, and fetch a whole screening analysis in one call (`api.v2.list_case_studies`, `get_screening_analysis_bundle`)

### Flowsheets

- **Breaking:** uploading flowsheets requires a screening analysis name, so each upload is linked to its analysis (`api.v2.upsert_flowsheets(screening_analysis_name=...)`); made optional again in v0.3.7

### Setup & configuration

- **Breaking:** the dev server is now chosen only when creating the client; the `dev` setting in `config.yaml` and the `PRISMA_API_DEV` environment variable are no longer read (`prisma_api.init(local_dev=True)`)
- Deprecated: `update_dev_mode()` now warns and will be removed; use `init(local_dev=True)` instead (`prisma_api.update_dev_mode`)
- A separate API key for the dev server can be set by environment variable, falling back to the production key (`PRISMA_API_DEV_API_KEY`)

# v0.3.0

https://github.com/RCCS-CaptureTeam/prisma_api/releases/edit/v0.3.0

_Released 2026-06-24_

### Flowsheets

- Fetch a flowsheet by name from the platform (`api.v2.get_flowsheet`)

### Materials & structures

- Material property bundles accept a `query` of filters per data type, so isotherms, Zeo++ data and water KPIs can each be filtered differently in one call (`api.v2.get_material_property_bundle(query=...)`)

### TEA / LCA data

- **Breaking:** the TEA equipment methods are renamed to plain equipment methods; update calls such as `get_tea_equipment_costs` to their new names (`api.v2.get_equipment`, `get_equipment_costs`, `get_equipment_designs`)

### Docs & examples

- README expanded with installation, API key setup, PSDI endpoint examples, pagination and return formats (`README.md`)

### Packaging

- New releases are now published to PyPI automatically, so `pip install --upgrade prisma_api` picks them up (`pip install prisma_api`)
